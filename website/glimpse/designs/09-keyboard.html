Show your screen. To people and to your agent.

Glimpse is one native macOS menu bar app for everything you show and tell from your screen. Capture it, mark it up, hand it off, keep it. Every step is a key.

Press 2–0, R, A, S, Enter or Shift twice. Or click a key.

Agents work it both ways

An MCP server lets Claude Code, Cursor and other agents use Glimpse themselves. Off until you allow it.

  • List windows and screenshot one, even when it is covered.
  • Read text on screen.
  • Record short clips to check their own work.
  • Draw arrows, boxes and notes in their own colour to show or ask you something.
  • Search meeting transcripts.
claude mcp add glimpse -- /Applications/Glimpse.app/Contents/MacOS/Glimpse mcp

The Claude Code plugin delivers what you send between turns.

Install

One line in Terminal. Free and open source under MIT.

curl -fsSL https://raw.githubusercontent.com/miladbeigi/glimpse/master/install.sh | bash
