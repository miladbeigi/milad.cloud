Glimpsev1.6.0 · free · MIT · macOS 14+

One native macOS menu bar app for everything you show and tell from your screen. To people, and to your AI coding agent.

  1. Capture an area, a window, a scrolling page or text. Or record the screen, or a meeting. Open ›
  2. Mark it up. Arrows, boxes, steps, notes, blur. Every mark stays editable. Open ›
  3. Hand it off. Copy, drag, pin, or press ⌘↩ to send it to Claude Code or Codex. Open ›
  4. Keep and find it. Double-tap right Shift for your last 30. Stitch several into one. Open ›

It works both ways: agents can use Glimpse too, through an MCP server you switch on.

Private: OCR, transcripts and voice profiles stay on the Mac.

Text, not pixels

Select any area and get its text. OCR runs on the Mac. Point it at a QR code and you get the link.

⌥⇧⌘2
Record Screen

Record to MP4

An area or the whole screen, with a camera bubble, your mic and system audio. ⌃⌥M mutes the mic.

⌥⇧⌘R
~/Glimpse/Meetings

Meetings, transcribed on the Mac

Glimpse notices calls in Meet, Zoom, Teams, Slack, Discord, FaceTime, Webex and Tuple. Record, and you get a transcript with speakers.

Each meeting is a markdown file in ~/Glimpse/Meetings. Audio, transcripts and voice profiles never leave the Mac.

Mark up

Every mark stays editable

Pencil-style curved arrows, boxes, numbered steps, highlighter, text, pixelate, blur, spotlight, crop. Type next to a box or arrow and the note lands beside it.

Hand off

It waits in the corner

Each capture waits in the Quick Access Overlay. Copy, save, or drag it into Slack, Mail or Finder. ⌥⇧⌘9 brings the last one back.

Pin to Screen

Pinned above everything

Float a capture above every window while you work beside it.

Send to Claude…

Straight to your coding agent

Press ⌘↩ to send a capture to Claude Code or Codex. With several sessions open, a menu lists them. The Claude Code plugin delivers it between turns.

⌘↩
Recent Screenshots

Your last 30, one gesture away

Double-tap right Shift and they slide in at the screen edge. Select several to copy, draw on, stitch or send.

⇧⇧or⌥⇧⌘0
Stitch

Several shots, one image

Stitch numbers each part and lays them out so an AI model shrinks the result the least.

Agents (MCP) · zsh
# Glimpse works both ways. Off until you allow it.
$ claude mcp add glimpse -- /Applications/Glimpse.app/Contents/MacOS/Glimpse mcp
# then Claude Code, Cursor and other MCP clients can:
  • list windows and screenshot one, even when covered
  • read the text on screen
  • record short clips to check their own work
  • draw arrows, boxes and notes in their own colour
  • search your meeting transcripts
