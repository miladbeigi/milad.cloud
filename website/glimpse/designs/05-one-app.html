Glimpse for macOS · free and open source

Four tools in your Dock, or one in your menu bar.

Most people run a screenshot tool, a screen recorder, a meeting notetaker, and now something to give their coding agent eyes. Glimpse is one native app that does all four, and passes work between them.

01

The screenshot tool

Grab any part of the screen, mark it up with edits that stay editable, and get it where it needs to go.

What you do · capture

Press a key, pick what to grab.

The screen freezes while you select, with a magnifier and the live size beside the cursor.

  • Area⌥⇧⌘4
  • Window, cut out⌥⇧⌘5
  • Whole scrolling page⌥⇧⌘6
  • Text (on-device OCR, QR)⌥⇧⌘2
  • Fullscreen⌥⇧⌘3
  • Previous area · self-timer⌥⇧⌘7⌥⇧⌘8
What you do · mark up

One key per tool. Every mark stays editable.

  1. Draw curved arrows, boxes, numbered steps, highlights.
  2. Type a note. It lands beside the box or arrow it belongs to.
  3. Blur or pixelate anything private, spotlight what matters, crop.

What you do · hand off

It waits in the corner until you need it.

  1. Hover the capture to copy or save, or drag it into Slack, Mail or Finder.
  2. Pin it above every window while you work.
  3. Lost it? ⌥⇧⌘9 brings back the last one.
02

The screen recorder

Record an area, a window or the whole screen to MP4. Your face in a bubble, your voice and the system sound in the file.

What you do

Start, talk, stop.

  • Start recording⌥⇧⌘R
  • Mute or unmute the mic⌃⌥M
  1. Pick the area. A dashed frame shows what is in the shot.
  2. Turn on the camera bubble and drag it where you like.
  3. Pause, restart or stop from the small control bar.
03

The meeting notetaker

It notices when a call starts, records it, and writes a transcript with speakers. All on your Mac.

What you do

Join the call. That is it.

Glimpse notices calls in:

MeetZoomTeamsSlackDiscordFaceTimeWebexTuple

A small pill shows the time, with mute, pause and stop. Afterwards you get a markdown file in ~/Glimpse/Meetings. Audio, transcripts and voice profiles never leave the Mac.

04

Eyes for your coding agent

Show Claude Code or Codex what you mean in one key. And let the agent look at your screen itself, when you allow it.

What you do · send

Mark it up, press ⌘↩.

  1. Draw on the capture: an arrow, a note, a question.
  2. Press ⌘↩. With several sessions open, pick one from the menu.
  3. The Claude Code plugin delivers it between turns, so nothing gets interrupted.
What the agent does · MCP

It looks, checks, and draws back.

With the MCP server on, Claude Code, Cursor and others can list your windows, screenshot one even when it is covered, read text, record short clips to check their own work, and search meeting transcripts.

When it wants to show you something, it draws on a screenshot in its own colour and leaves it in your recent stack. Off until you allow it.

claude mcp add glimpse -- /Applications/Glimpse.app/Contents/MacOS/Glimpse mcp

And they work together.

Four separate tools hand you four separate files. In Glimpse every job feeds the next one, so a capture or a call is never stuck where it started.

Scripts can join in too: glimpse:// URLs work from Shortcuts, Raycast or a shell script.

Swap four for one.

Paste this into Terminal. It installs Glimpse into Applications, and Glimpse updates itself from then on.

curl -fsSL https://raw.githubusercontent.com/miladbeigi/glimpse/master/install.sh | bash
Then, for Claude Code
claude mcp add glimpse -- /Applications/Glimpse.app/Contents/MacOS/Glimpse mcp
